# CODDY — главная страница

Адаптивный дизайн-прототип главной страницы онлайн-школы CODDY.

## Запуск

Откройте `index.html` в современном браузере. Сборка и установка зависимостей не требуются. Фирменные изображения находятся в `assets/` рядом со страницей.

Для загрузки шрифта Manrope нужен доступ к интернету; без сети используется системный sans-serif шрифт.

## Возможности

- Адаптивная навигация с мобильным меню и якорями.
- Каталог из 9 курсов с поиском, фильтрами по возрасту и направлению и раскрытием списка.
- Окно с описанием курса и переходом в каталог CODDY.
- FAQ на аккордеоне, разделы о школе, отзывах и фирменных материалах.
- Ссылки на официальный сайт, программы и контакты CODDY.

Это неофициальный дизайн-прототип: заявки не отправляются. Названия программ, сведения о школе и отзывы приведены для демонстрации; актуальную информацию уточняйте на [официальном сайте CODDY](https://coddyschool.com/).
